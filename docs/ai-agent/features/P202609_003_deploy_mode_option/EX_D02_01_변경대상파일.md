# `[D02]` 변경 대상 파일 및 영향도 (#P202609_003)

정본은 [spec.md](spec.md). 상세 설계는 [EX_D01_01](EX_D01_01_배포방식설계.md).

## 스크립트 (배포서버에서 도는 것)

| 파일 | 변경 | 영향 |
|---|---|---|
| `bundle_config/deploy/script/windows/deploy.bat` | `DP_MODE=copy\|swap` 분기 · `DP_EXCLUDE` 신설 · copy 경로 추가 | ⭐ 핵심. 두 방식이 한 파일에 산다 — 정지·시작·원복 로직을 공유하므로 나누면 #P002 가 없앤 복붙이 재현된다 |
| `bundle_config/deploy/script/windows/rollback.bat` | ⭐ **복귀 원본이 폴더에서 zip 으로 바뀐다.** 확정 zip 전개 → 배포와 같은 경로 | `RB_MODE` 와 축이 다르다. `RB_MODE`(consume/copy)는 **백업을 어떻게 소비하나**이고 새 축은 **어떻게 되돌리나**다. 이름 충돌 주의 |
| `bundle_config/deploy/script/windows/webserver_iis.bat` | `stop` 후 w3wp 종료 대기 (`appcmd list wp`) | 두 방식 공통. 이것만으로 2026-09-22 실패가 막혔을 가능성이 있다 |
