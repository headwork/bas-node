## 1단계 — 잠금 견고화 (#P003-REQ5, OQ 무관 · 즉시 효과) ✅ 2026-09-23

  1초 간격으로 기다린다(`WS_WP_WAIT`, 기본 15초). **절대 실패로 내리지 않는다** — 상한을 넘기면
  경고만 남기고 진행한다. 늦게 죽는 풀을 실패한 배포로 바꾸면 안 되고, 어차피 호출자의 에러가 더 정확하다.
  `timeout` 대신 `ping` 을 쓴다 — `timeout` 은 stdin 이 리다이렉트되면 거부하는데 ssh 실행이 정확히 그 모양이다.
  검증: 스텁 appcmd 로 두 경로 확인(워커 없음 → 57ms 즉시 반환 / 계속 살아 있음 → 대기 후 경고, 종료코드 0).
* ✅ `#P003-TASK2`: `src/deploy/lockDiag.js` 신규 — 종료코드 `1`(폴더를 못 옮김)에서
  **그 폴더를 잡은 프로세스를 이름·PID 로 찍는다.** 로컬·원격이 같은 명령을 쓴다(둘 다 cmd 가 받는다).
  ⚠️ 큰따옴표·파이프를 쓰지 않는다 — ssh 인용과 겹치고 cmd 가 파이프를 먼저 먹는다. 테스트로 못 박았다.
  잡히지 않으면 **"없다"가 아니라 "찾지 못했다"** 고 말한다 — 탐색기·cmd 의 현재 디렉터리는 이 방법으로 안 보인다.
  절대 던지지 않는다(던지면 원래 실패 사유가 가려진다). 검증 9건, 실제 실행 1건 포함.
* ✅ `#P003-TASK3`: `src/deploy/decodeOutput.js` 신규 — `execSync` 의 `encoding:'utf8'` 고정 해석을 걷어내고
  **UTF-8 로 읽어 U+FFFD 가 나오면 CP949 로 다시 읽는다.** 순서를 뒤집으면 안 된다(UTF-8 을 CP949 로 읽으면
  깨진 채로 성공한다). 2026-09-22 실패에서 원인 한 줄이 이 때문에 가려졌다. 검증 7건.

## 3단계 — 확정 단계와 백업 구조 전환 (#P003-REQ4, REQ9, REQ11) ✅ 2026-09-23

* ✅ `#P003-TASK7`: **`ConfirmStage` 신설** — 헬스체크 뒤에 놓고 **이름 변경·삭제를 전부 여기로 모았다.**
  배포 직후에 돌던 원격 백업 정리·잔여 폴더 정리도 옮겼다. 로컬·원격이 같은 인터페이스
  (`mkdir·copyFile·move·remove·listDirs·listFiles`)를 쓰므로 위층은 어느 쪽인지 모른다.
  실패해도 배포를 뒤집지 않는다 — 여기까지 왔다는 것은 서비스가 이미 정상이라는 뜻이다.
* ✅ `#P003-TASK8`: **확정 zip 세대 보관**(`_builds\<live>_<stamp>.zip`)으로 갈아탔고
  **폴더 백업은 폐기했다**(전환기 없음 — 위 지시). 확정 때 `_org_` 는 사본을 뜨지 않고 지운다.
  이력의 `backup_path` 도 더 쓰지 않는다 — 만들지 않는 폴더를 남기면 롤백 목록이 거짓말을 한다.
  옛 규칙으로 쌓인 폴더 백업은 보관 정책이 계속 쓸어낸다(서버에 남아 있다).
* ✅ `#P003-TASK9`: `backupRetention` — `selectByPattern` 으로 파일(.zip)·`_preserve_` 에도 같은 정책 적용,
  **`_org_` 를 잔여 패턴에 추가**(확정이 못 돌고 끝난 배포의 흔적을 다음 성공 배포가 치운다).
* ✅ `#P003-TASK10`: 명명 규칙을 `backupRetention` 한 곳에 모았다 —
  `stagingName`·`orgName`·`preserveName`·`releaseName`·`releaseDir`. **한 배포 = 한 스탬프.**
  🔴 **같은 초 충돌을 실측했다** — 확정 zip 이름이 겹치면 앞 판이 **조용히 덮인다**(되돌릴 지점이 하나 사라진다).
  `#freeName` 으로 `_2` 를 붙여 비켜 간다. 테스트가 이것을 잡았다.
* ✅ `#P003-TASK11`: `rollback.bat` 을 다시 썼다 — 원본이 **확정 zip(전개)** 또는 **`_org_` 폴더(전개 없음)** 둘 중 하나.
  `RB_MODE`(consume/copy)는 사라졌다: 확정 zip 은 전개해도 원본이 줄지 않는다.
* ✅ `#P003-TASK12`: ~~QA 에서 zip 롤백을 먼저 성공시킨 뒤 폴더 백업을 끊는다~~ **취소**(2026-09-23).
  QA 는 되돌릴 수 없어도 되고, 백업이 없으면 롤백은 *"확정 빌드가 없습니다"* 로 멈춘다 — 그것으로 충분하다.
  🔴 **함께 잡은 것**: `--rollback --dry-run` 이 세는 목록(`rollbackCandidates`)과 실제 롤백이 고르는
  목록(`releaseCandidates`)이 **달랐다.** 3번으로 보인 판과 `--rollback=3` 이 되돌리는 판이 어긋나는데
  **에러가 나지 않는다.** 목록을 하나로 합쳤다.
